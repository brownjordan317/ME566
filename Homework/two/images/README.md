# Add your camera images here

Use these file names (any common image extension is fine), then open
`report.ipynb` and choose **Run All**.

| Question | Required image files | What to photograph |
|---|---|---|
| 1 | `q1_original`, `q1_scaled`, `q1_translated`, `q1_rotated` | The same textured, mostly planar scene captured at different camera scale, position, and rotation. |
| 2 | `q2_input` | One textured image that makes it easy to see the spatial distribution. |
| 3 | `q3_left`, `q3_right` | Two views of the same mostly planar, textured scene. |

Examples: `q1_original.jpg`, `q3_right.png`.  Do not digitally rotate or
resize images for Question 1. The notebook accepts additional `q1_*` images
and includes all of them in the comparison.
