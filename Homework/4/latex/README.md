# HW4 report

`report.pdf` is the final IEEE-style writeup for tasks 1–6, including conditional pose uncertainty. `report.tex` is the editable source. The title, author and two-column format follow the HW3 report.

From the ME566 repository root, run the calibration and shared-orientation commands in the report, then:

```bash
MPLCONFIGDIR=/tmp/hw4_mpl .venv/bin/python Homework/4/build_report.py
cd Homework/4/latex
pdflatex -interaction=nonstopmode -halt-on-error report.tex
pdflatex -interaction=nonstopmode -halt-on-error report.tex
```

`uncertainty.json` and `pose_covariance.npz` contain the extra-credit results. `measurements.tex`, `numbers.tex`, and `figures/` are regenerated by `build_report.py`. Source is packaged in `../outputs/hw4_source.zip`; original captures accompany it in `../hw4_captures.zip`. IEEEtran.cls is reused from HW3 and includes its upstream license text.
